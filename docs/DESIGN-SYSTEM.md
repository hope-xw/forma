# 本地变量与样式

0.6.2 的本地样式编辑沿用图层的渐变、填充堆栈和阴影数据。渐变色标可保留变量引用，修改透明度只更新透明度通道。颜色样式上直接修改基础颜色会解除该通道的绑定；应用到选区的样式由现有事务写入并随设计文件保存。锁定图层的绑定和模式选择会禁用。[交互规格](specs/EDITOR-UI-CONTROLS.md) · [重开验证](EDITOR-ACCEPTANCE.md#062-面板复核)

**0.5.0**　公开属性更名保留稳定 ID 和目标模板键，发布后按独立消费文件保留实例覆盖；React 工程继续接受该字段的旧名。[操作和继承规则](specs/PROFESSIONAL-EDITING.md)

**0.4.0**　主件可公开子层文本和显示属性。库快照包含字体以及使用的图像、变量与样式。资源面板可以发布或订阅 HTTP 修订，使用方可挑选组件和解决共享定义冲突。 [规格与操作入口](specs/PROFESSIONAL-EDITING.md)


点击顶栏的「变量与样式」，从空集合开始，或选「添加 Forma 基础体系」。现有文件不会自动换色。选中图层后，通过右侧字段旁的变量按钮绑定属性；填充、文字和效果区也可以从选区创建样式。空选区设置文件模式，选中画板则可覆盖该画板及子树的模式。

## 能力与验收边界

| 项目 | 已实现 | 当前边界 |
| --- | --- | --- |
| 变量 | 颜色、数值、字符串、布尔；集合、模式、同类型别名、适用属性和代码名 | 颜色变量以六位 HEX 存储，在文件指定的 sRGB 或 Display P3 色域中解释；颜色透明度单独存储。数值变量不带单位 |
| 模式 | 文件默认值、画板及图层覆盖、后代继承；跨集合的别名按各自模式解析 | 现有组件库的明暗变体不会自动转换为变量绑定 |
| 样式 | 填充、文字、效果、布局网格四类；定义可引用变量；源更新同步到引用层；局部覆盖、解除引用保留当前外观 | 网格样式用于画板；填充层数受原生格式限制。跨文件更新通过库文件传递引用定义 |
| 手动编辑 | 属性面板按选区分组；色板、HEX/RGB/HSL、透明度、文件色、可用时的系统吸管；每个渐变色标可选填充颜色变量 | 吸管取决于浏览器；不能把平台特有材质等同于 CSS 效果 |
| 文件与代码 | 原生 JSON 导入导出、跨文件复制时重映射引用、撤销重做；React ZIP 附 `design-system.json`、`src/tokens.css` 和 `src/tokens.ts` | 交换格式为 Forma JSON。文字内容、布尔可见性及原生控件几何取导出时的值；改这些变量后需要重新导出 |

原生基础体系有 3 个集合、40 个变量、8 个样式。`Primitives` 保存基础值；`Semantic` 使用别名区分 Light / Dark；`Layout` 管理 Comfortable / Compact 的间距、圆角和字号。同一画板可以独立选择颜色和密度模式。引用不存在、类型不符、循环别名以及不合法的模式值会使整个事务失败。

## 后续迭代

1. 增加复合颜色与透明度变量及标准 Token 文件互操作；以双向往返时引用、单位、模式不丢失为验收条件。
2. 组件库已随组件携带实际引用的变量、各模式别名链和样式，外部文件导入会处理 ID 冲突。内置库第二版给移动控件提供专用语义色，保留插画用色与指定的变体外观。

同文件的主件变化会传播到其他页面的实例并保留允许的覆盖。跨文件通过同一标识的更高版本库文件更新已有关联，事务保留兼容覆盖，冲突时可另存独立副本。已执行的主题往返检查见[编辑器验收记录](EDITOR-ACCEPTANCE.md)。
3. 在已验证的本地文件交换之上，补在线修订发现、按组件选择更新与团队权限。

本地主组件的附加变体以 `masterNodeId` 关联同文件的源图层。此前创建的单变体继续沿用 `component.master`。主件的每个变体可分别编辑和传播，已有实例保持引用与逐层覆盖。新建、组合、改名与移出操作见[设计师操作规格](specs/PROFESSIONAL-EDITING.md)。
