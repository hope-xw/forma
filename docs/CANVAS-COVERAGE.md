# Figma 画布与图层操作核对 · 2026-11-17

**0.4.0**　选中网格画板可在画布拖动列宽、行高；拖动子层可定位到指定单元格。图层树可选中位图蒙版来源，属性栏切换透明度和亮度。F6 在画布与面板之间移动。 [规格与操作入口](specs/PROFESSIONAL-EDITING.md)


本次补的是设计师的手动编辑链路。对照用户 PDF 中 F07、F10–F17、F25、F30，以及 Figma 官方选择、剪贴板、视图和键盘文档。下面列出已经落地的具体操作，不能把这些子集理解为 Figma 整条规格的全部能力已完成。

| 对照项 | 本次实现 | 入口与行为 | 验证 |
| --- | --- | --- | --- |
| F07 Frame / Group | 编组、取消编组、包裹为 Frame；Group 随子层范围改变边界，Frame 保持固定尺寸 | ⌘G / ⇧⌘G / ⌥⌘G；取消编组保持原子对象 ID 和世界坐标 | 内核坐标测试、浏览器编组/取消编组 |
| F10 上下文属性 | 单选属性、多选 Mixed、批量赋值、容器选择、锁定隐藏 | 输入数值后 Enter / 失焦提交；多选编辑只改指定属性 | 浏览器批量改宽度及一次撤销恢复差异 |
| F11 选择与层级 | 浅层选取、修饰键穿透、双击进入、Enter 子层/文字、Shift Enter / Esc 父层、Tab 相邻层 | 画布与图层选区一致；父层锁定时子层不可编辑 | 嵌套选择与锁定测试 |
| F12 多选 | Shift 点击增减画布选区；层树 Shift 连续选择、⌘/Ctrl 增减；框选、容器内深框选、上下文全选 | 容器空白处 ⌘/Ctrl 拖动框选内部对象；同时选父子只对根选区执行移动/复制 | 浏览器深框选、多选、Mixed；父子去重单测 |
| F13 画布导航 | 手形、空格临时平移、中键平移、滚轮双轴平移、缩放锚点、5%–800% 缩放、适应全部/选区、100% | H；空格拖动；⌘/Ctrl 滚轮或触控板 pinch；+/−；Shift 1 / 2 / 0 | 缩放几何测试；实际平移和滚轮验证 |
| F14 / F16 几何整理 | 6 种对齐、水平/垂直等距分布、边缘/中心吸附、Alt 悬停间距提示 | 右侧面板或命令菜单；分布至少 3 个对象；自动布局子项用布局规则控制 | 对齐分布/吸附单测；多选面板检查 |
| F15 命令入口 | 命令搜索、右键菜单、快捷键帮助，共用命令入口 | ⌘/Ctrl K、右键、?；菜单支持方向键导航 | 浏览器命令搜索和右键副本 |
| F16 手动几何 | 自由布局拖动、八方向尺寸把手、Shift 等比、Alt 中心缩放、多选几何缩放、1/10px 微调、Shift 单轴拖动 | 画布把手；方向键 / Shift 方向键；按 Esc 取消未提交手势 | 浏览器拖动/缩放/微调；手势整次撤销 |
| F17 / 布局插入 | 自由/水平/垂直布局；画布拖动在自动布局内重排；跨 Frame 拖放；Shift A 建立自动布局 | 自动布局流内不写死视觉 x/y，通过 sibling order 重排 | 浏览器自动布局顺序和撤销 |
| F25 文本编辑 | T 点击/拖动创建、双击原地编辑、多文本内容批改 | 中文文本；⌘/Ctrl Enter 提交、Esc 放弃；输入态不抢设计快捷键 | 浏览器中文编辑及取消；真实 IME 候选窗口尚未手测 |
| F30 基础绘制 | Frame、矩形、椭圆、文本、按钮 | F/R/O/T 工具与资源面板；拖动创建；Shift 等比绘制 | 浏览器绘制原生对象 |
| 剪贴板补充 | 剪切、复制、粘贴、原位粘贴、副本、Alt 拖动副本、纯文本粘贴、样式复制粘贴 | ⌘X/C/V/D；⇧⌘V；⌥⌘C/V；复制整棵子树、更新 ID、保留绑定、变量冲突改名 | 浏览器系统剪贴板与原位粘贴；跨文件 Token 冲突单测 |
| 图层管理补充 | 折叠、检索、重命名、隐藏/锁定、继承锁定、删除、图层拖放/重排、父容器下拉、置顶置底/上下移层 | 层树拖到上/下四分之一区域排序，中间移入容器；根层落点移出容器；⌘R 重命名 | 浏览器层树多选拖放、隐藏恢复；锁定与顺序单测 |
| 恢复 | 撤销/重做恢复文档及选区、手势预览不保存中间状态、剪切失败保留原稿、刷新读取已保存文件 | 一次拖拽一个历史记录；操作失败不产生半成品 | 浏览器副本重做后继续复制、尺寸手势撤销与刷新恢复 |

⌘ 在 Windows/Linux 对应 Ctrl；Mac 快捷键已在 Chromium 中实测，其他浏览器/平台的系统级快捷键冲突尚未逐一验证。

## 2026-11-19 复核

多页、本机文件、旋转/翻转、钢笔、直线、可调边数的多边形与星形、布尔、标尺辅助线、二维智能整理、图层树虚拟化、局部文字样式、图像、水平 Wrap、Grid 和约束已接入编辑器。具体操作和限制见[当前验收记录](EDITOR-ACCEPTANCE.md)。系统级 IME、多浏览器剪贴板、复杂 SVG 滤镜、多人共享与大文件整段交互仍需独立验证。

## 实现组织

- `domain/tree.ts`：层级、根选区、锁定与可见性。
- `domain/geometry.ts`：文档坐标、视口变换、固定布局边界、尺寸调整与吸附。
- `domain/editing.ts`：编组、解组、重排、跨容器移动、对齐/分布。
- `domain/clipboard.ts`：可校验的剪贴板协议、ID/变量引用映射。
- `editor/useDocument.ts`：提交状态与手势预览分离、错误处理、持久化。
- `editor/useEditor.ts`：选区、命令分发、快捷键、系统剪贴板、撤销选区恢复。
- `editor/Canvas.tsx`：指针手势状态机、视口、选择覆盖层、文本编辑。
- `editor/LayersPanel.tsx` / `Inspector.tsx` / `ActionMenu.tsx`：统一使用相同命令，避免维护平行的修改逻辑。

## 组件操作补充（2026-11-17）

图层树显示组件菱形和受保护实例标识，默认折叠；深选内部图层时显示所属组件。组件默认保护结构与内部几何，整体移动/删除/复制可用，内部文字和外观可覆盖。修改内部层级、增删子层与尺寸必须先显式分离，撤销恢复实例保护。画布、层树、快捷键、Inspector 与 Agent 使用同一事务检查。

新增线性/径向渐变（2–8 色标、位置与透明度）与复制样式过滤布局属性。组件及其子层上的粘贴和资源插入落到同级容器。剪贴板权限超时回退到内部缓冲；异步等待期间文档变化会拒绝陈旧操作。

此节记录 11 月 17 日的实现。旋转、约束、图像、富文本、多页面与协作的最新状态见[当前验收记录](EDITOR-ACCEPTANCE.md)。
