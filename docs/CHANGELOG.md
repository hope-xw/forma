# Forma 版本更新日志

本文按发版时间倒序记录每个版本的完整更新内容、问题修复与兼容说明。产品内「版本日志」面板会展示面向设计师的精简摘要，日常小修补会归并到下一次重要更新中统一呈现。详细维护规范见[发布与归并规则](specs/VERSIONING-AND-DESKTOP.md#4-文件菜单里的版本日志)。

## 0.12.0 · 2026-11-26

- Forma AI 体验重构：左侧 AI 面板升级为满高三段式设计师对话工作区，高级偏好与外部 MCP 接入收纳至底部「创作设置」浮层，去除重复未配置引导、裸坐标与内部协议术语，同步打磨画布内联对话条
- 分层错误边界与空画布引导：新增 ErrorBoundary 隔离顶层/侧栏/画布/属性/弹窗故障并提供防丢稿 .forma.json 应急导出；空白文件居中提供非阻塞「开始你的新设计」快速开始卡
- 桌面/Web 心智与导航打磨：桌面客户端保存状态显示「已保存到本机」并移除 IndexedDB 研发术语，画板预设统一为全中文分组，左侧导航栏以细分隔线区隔主视图与工具入口
- 工程架构与样式治理：迁移纯领域模块与纯 SVG 序列化、抽离零 React 依赖的 AI 应用层并上线 npm run lint:arch 门禁；全面落地 5 级 CSS @layer 架构，!important 从 223 降至 3；主入口 JS 体积经懒加载与 vendor 分包缩减 53.3%

## 0.11.0 · 2026-11-26

- **新增**：上线 **Forma AI Stage 2 · 轻量项目空间（Project Space）**——升级「本机文件」弹窗（`FileBrowser`）为两栏项目空间管理，支持项目新建、重命名、安全删除（释放文件回未归类草稿，不删设计文件）及默认组件库绑定；未归类草稿默认按 `file:<fileKey>` 独立隔离记忆，归入项目后单稿档案自动随迁至 `proj:<projectId>` 并实现同项目多稿共享；编辑器顶栏实时显示所属项目徽章。[Forma AI 组件库与记忆规格](specs/FORMA-AI-LIBRARY-AND-MEMORY.md#四轻量项目空间历史需求记忆与衍生模块回流stage-2已实施并验收)
- **新增**：上线项目级《历史需求档案（`DesignEpisode`）》离线沉淀、管理与 L2 召回——采纳侧栏或画布 HUD 提案自动沉淀结构化档案（画板清单、复用组件计数、自建模块、已确认决策、中英混合关键词与清洗后 SVG 缩略图），零模型网关时也可在「历史需求档案」抽屉手动归档当前画板、搜索、置顶（100 条作用域上限置顶保护）与删除；侧栏与画布 `@` 菜单新增「历史需求」标签页，`rankProjectEpisodes` 按 `Project × Library` 确定性混合召回并在服务端挂载 `search_project_episodes` / `get_episode_details` 只读工具。
- **新增**：打通衍生模块一键回流组件库闭环（`PromoteModuleModal`）——支持从画布右键菜单、左侧资源面板与 AI 应用后操作栏一键将模块沉淀至项目衍生库（`proj-lib-<id>`）或自定义组件库（严格保护四大官方内置只读库），自动推断资产层级、合并样式/变量/字体/图片依赖、递增修订号并增量刷新目标库 `aiGuide` 说明书（严格保留 `<!-- forma:custom-notes -->` 手写备注），同步写入工作区仓库供跨文件复用，支持可选原地替换为受保护实例与单步 `⌘Z` 撤销。
- **加固**：新增独立 `forma-project-memory-v1` IndexedDB 存储与 `forma-workspace-libraries-v1` v2 独立围栏仓；在 `storage.ts` 引入每文件 `lifetimeToken`、单调 `replacementEpoch`（覆盖整稿导入、页面样例重载、失败恢复与跨替换边界 Undo/Redo）以及与文档写删串行化的 2PC 提交授权协调器，前置校验损坏分片头保障历史版本可恢复，新增 **+300 项**单测（全仓 **895 / 896** 通过，1 项跳过需浏览器原生 IndexedDB）。
