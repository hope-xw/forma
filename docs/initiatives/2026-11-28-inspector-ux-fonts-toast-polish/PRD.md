## 一、背景与全量走查发现

基于 `v0.17.0` 桌面端实机试用反馈与针对右侧属性面板（20 个组件、304 处原生控件声明）的全量只读深查，确认以下 3 类核心痛点及连带隐藏缺陷需一次性根治：

1. **文字转轮廓受系统字体与字体格式限制（用户实机反馈 #1）**
   - 选中默认文档中「让好设计，发生。」（`system-ui, sans-serif`）点击「文字转轮廓（`⇧⌘O`）」，直接弹出红框报错要求手动导入 TTF/OTF；
   - 混合中英文（如 `Forma 设计 2026`）在主字体缺字形时直接失败，缺少按字形回退链（Latin + CJK 自动衔接）；
   - 字体导入与解析仅接受裸 TTF/OTF，拒绝 `.ttc`/`.otc` 字体集与 `.woff`/`.woff2` 常见字体格式。
2. **提示信息位置异常、样式非标准 UI3 且遮挡工具栏与弹层（用户实机反馈 #2）**
   - `App.tsx` 中的旧版 `.toast` 固定在窗口右下角（`right: 20, bottom: 18`），自带醒目 1px 红边框大白底，直接压在画布底部浮动工具栏与右侧属性栏底部（如「导出」区）之上，并和打开的颜色选择器互相遮挡；
   - 错误态会静默压制 `statusToast`，11 处懒加载占位也误复用 `.toast` 类。
3. **颜色选择器及右栏全部 5 类弹层未按可视窗口动态适配位置（用户实机反馈 #3）**
   - `ColorField`（硬编码 `440px`）、`TokenBinding`（`310px`）、`StyleBinding`（`280px`）、`type-details-popover`（`360px`）、`SlotSwapPicker`（`320px`）均未测量真实 DOM 尺寸，在低位触发、窗口缩放或属性栏滚动后底部控件被直接裁出视口；颜色选择器拖出边缘还会累积死区偏移。
4. **右侧属性面板全量深查暴露的文档完整性与控件缺陷**
   - **文档完整性 P0**：存在外部 AI 提案预览时，右侧属性栏宽度/颜色/面板操作可误清提案并直接提交；多选不同控件类型（如输入框 + 开关）修改「更多属性 → 可访问名称」会把开关覆盖成输入框；
   - **P1/P2 系统性缺陷**：次级原型规则缺少 URL/过渡/类型过滤变量编辑；DevMode 备注草稿切层串写与锁定态误清；导出面板首字符输入失焦与子集批量导出文件名漂移；`LayoutGuides` / 共享 `Field` / `Prototype` 的 `Escape` 误提交与 IME 提前提交；渐变/色板透明度/矢量描边/缩放/网格/断点/尺寸限制的空值与越界校验不统一；独立边描边在 `80px` 统一描边切换时触发 64 上限报错；选区纯色漏掉 `tint`/`fillFromStyle` 且改色即卸载打开的取色器；P3 颜色对比度未转 sRGB；256px 窄栏长集合名挤压与多 Tab 全局 `getElementById("right-panel")` 分隔线跳宽；异步换图竞态；键盘焦点与 `aria-describedby` / 字距图标 / 渐变文案 / 阴影上限提示等 UI3 细节缺口。

## 二、核心目标（本轮 `v0.18.0` 必达）

1. **系统字体与全格式字体文字转轮廓**
   - 桌面端（Electron IPC）与本地 Web 开发/预览（回环服务）自动解析操作系统已安装字体（含 macOS `PingFang.ttc`、`SF Pro`、`Hiragino Sans GB`、`Helvetica Neue` 及用户字体目录），纯 Web 环境优先回退 Chrome/Edge `queryLocalFonts()`；
   - 支持 **TTF / OTF / TTC / OTC / WOFF**（及可用环境下的 **WOFF2**）容器解码与单面规范化，支持**按字形多字体回退链路**，令默认中文标题「让好设计，发生。」与中英混排文案一键精准转为真实矢量贝塞尔轮廓，保留稳定图层 ID、`⌘Z` 单步撤销与 React 导出一致。
2. **Forma UI3 标准 `<ToastHost />` 轻提示体系**
   - 抽离独立可复用的 `ToastHost` 组件：锚定于当前活跃画布顶部居中（画布顶边下方 `12px`，严禁压挡底部浮栏、右侧属性栏、小地图与已展开弹层）；
   - 严格使用 UI3 悬浮表面令牌（`--bg-elevated`、`--border-subtle`、`--shadow-popover`），以语义图标与柔和色条区分 `info` / `success` / `warning` / `error`，支持队列去重、`info`/`success` 4.5s 自动收起（悬停/聚焦暂停）与可关闭错误态，11 处懒加载占位迁出 `.toast`。
3. **统一视口自适应弹层引擎（`useAnchoredPopover`）覆盖右栏全部 5 类弹层**
   - 真实 DOM 测量 + `ResizeObserver` + 窗口 `resize` + 面板滚动重算，智能选侧/向上翻转/双轴钳制 + 基于落点 `top` 的动态 `max-height` 与独立滚动主体；
   - 修复颜色选择器有界拖拽零死区与全键盘焦点回返。
4. **右侧属性面板全量缺陷清零**
   - 全面关闭上述 2 项文档完整性 P0、全部 P1 子面板行为/校验/焦点/窄栏缺陷与 P2 图标/文案/无障碍打磨，并通过多视口（`1440×900`、`1280×720`、`1024×600`、`1024×480`）× 双宽（`256px`/`280px`）真实 Chromium 自动化与 2× Retina 实拍验收。

## 四、验收标准（DoD）

1. **门禁**：`npm run format:check`、`npm run lint:arch`（`0 violations`，`as any <= 1`，`CSS !important <= 3` 零新增）、`npm run build` 全过。
2. **独立只读复审**：经独立只读 Codex CLI Code Review 清零全部 P0 / P1 并签核 **PASS**。
3. **测试与真机验收**：
   - 全仓单测 0 失败（新增系统字体/多格式转轮廓、弹层/Toast、右栏子面板与文档完整性 4 组回归测试）；
   - 新增真实 Chromium E2E `inspector-ux`（覆盖默认中文标题「让好设计，发生。」转轮廓、`1440×900`/`1280×720`/`1024×600`/`1024×480` 四档视口下全部 5 类弹层 0 越界、`ToastHost` 0 遮挡、256px 窄栏与两项文档完整性场景）+ 既有核心 E2E 全过；
   - 采集 2× Retina 深浅双主题实拍逐张人工复核；
   - 通过 `npm run release:run` 同步发布 **`v0.18.0`** 并完成只读挂载 `Forma-0.18.0-arm64.dmg` 实机验收（含 Electron 桌面端系统字体转轮廓实机核验）。
