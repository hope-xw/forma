## 一、背景与已确认痛点

基于 `v0.16.0` 实机试用反馈与既定两阶段画布路线图，本阶段集中解决 4 类直接影响专业设计师日常创作与百屏大稿流畅度的核心问题：

1. **画板标题无法拖拽移动，画板区操控不够顺手（用户实机反馈 #1）**
   - 当前 [Canvas.tsx](../../../src/editor/Canvas.tsx) 中 `.frame-label` 的 `onPointerDown` 仅选中画板并阻止冒泡，拖动标题完全无响应；当画板已选中或内部铺满子图层时，设计师只能费力寻找画板空白缝隙拖动；
   - 双击画板标题仅切换左侧图层树的重命名状态，当左栏折叠或切到资源/AI 页签时毫无反馈；
   - 右键点击画板标题因缺少节点标识会误清空选区；`section` 分区标题胶囊（`.section-title-pill`）设置 `pointer-events: none` 无法拖拽，且放在 `section` 内部的顶层画板缺少可拖拽标题。
2. **属性面板对齐图标与语义/行为横纵错位（用户实机反馈 #2）**
   - [Inspector.tsx](../../../src/editor/Inspector.tsx) 误用了 Lucide 图标的水平/垂直命名（将顶/中/底横轴基准线图标 `AlignStart/Center/EndHorizontal` 映射给了左/水平中/右对齐，将左/中/右竖轴基准线图标 `AlignStart/Center/EndVertical` 映射给了顶/垂直中/底对齐），导致悬停「顶对齐」却显示「左对齐」图标；
   - 自动布局容器内的 `absolutePosition: true` 绝对定位子图层在 UI 中允许对齐，但 [editing.ts](../../../src/domain/editing.ts) 未对其放行，存在前后端校验不一致。
3. **50–150 屏全景缩远浏览时 DOM 树过重**
   - 当页面包含 50–150 张高复杂画板（万级图层）且用户缩远至 `< 40%` 俯瞰全局时，屏幕内同时可见大量画板，若全部保留深层活 DOM 节点，平移与重排压力依然明显。需要实现「远景自动切换轻量离屏缩略瓦片、放大或选中/编辑瞬切清晰活 DOM」的智能动静切换机制。
4. **高级矢量编辑能力缺口**
   - 当前 [VectorEditor.tsx](../../../src/editor/VectorEditor.tsx) 仅支持单锚点选择与拖拽，缺少多锚点框选批量调整、直接拖动曲线段弯曲（Bend 工具）以及设计师高频使用的描边轮廓化（Outline Stroke）与文字转矢量轮廓（Outline Text）。

## 二、核心目标（本轮 Phase 2 必达）

### 1. 画板区域交互全面对齐 Figma 手感
- **标题全功能拖拽**：页面根画板、组件集、分区（`section`）以及直接位于分区内的顶层画板标题均支持：
  - 左键点击选中、`Shift+点击` 增减多选；
  - 左键按住直接拖动整板（多选时联动拖动全部选中项），完整享有智能吸附红线、`Shift` 轴向锁定、`Option/Alt` 拖出复制副本、拖入/拖出 `section` 自动重挂、松手单步原子提交与 `⌘Z` 撤销；
  - 双击标题在画布原位弹出紧凑重命名输入框（兼容中文 IME `isComposing`、`Enter`/失焦提交、`Esc` 取消，不依赖左侧图层面板是否展开）；
  - 右键点击标题自动聚焦该画板并弹出上下文菜单；
  - 悬停标题时对对应画板呈现清晰的悬停高亮外框；
  - 在空格平移、抓手工具、绘图工具、框选或 DevMode 下自动让位透传指针，且与顶部缩放边缘留足安全间距防误触；锁定画板禁止拖动与重命名。
- **画板区域全套交互验收**：覆盖空白画板/满内容画板拖标题移动、拖空白区移动、双击钻取子层、`⌘+点击` 直穿子层、`⌘+框选` 画板内子图层、多画板框选后拖任一标题整体平移与撤销。

### 2. 对齐与分布图标、语义与行为 100% 精准一致
- 彻底校正右栏 6 枚对齐图标与 2 枚分布图标的 SVG 几何与中文语义对应（`左对齐` / `水平居中` / `右对齐` / `顶对齐` / `垂直居中` / `底对齐` / `水平等距分布` / `垂直等距分布`），与 Figma 标准顺序、视觉方向和实际像素移动结果逐一核对；
- 修复自动布局内绝对定位子图层（`absolutePosition: true`）在 `alignOperations` 中与属性面板的一致性；
- 采集 2× Retina 对齐工具栏高清特写实拍并逐枚人工核验。

### 3. 50–150 屏远景智能缩略缓存与动静切换（Board LOD Cache）
- **智能切换策略**：当页面达到多画板规模（根画板 `>= 12` 或总节点 `>= 600`）且视口缩远至远景阈值（带滞回防闪烁：`< 38%` 进入缓存态，`>= 42%` 回归活 DOM），屏幕内非活跃的高复杂根画板自动切换为单 DOM 轻量离屏缩略瓦片（Canvas2D 结构化快速绘制 + 分帧空闲调度 + LRU 内存预算限制）；
- **零糊感与零交互阻断**：选中的画板、悬停画板、编辑中/拖拽中/AI 预览中画板、开启线框/参考网格模式或极简画板（`<= 8` 节点）始终保持清晰活 DOM；点击任意远景缓存画板瞬间选中并无缝切换回活 DOM；文档任意修改或主题变量切换按分支签名精确失效缓存，永不显示脏图。

### 4. 高级矢量编辑（多锚点框选 + Bend 弯曲 + 描边/文字转轮廓）
- **多锚点框选与批量操控**：矢量编辑模式下支持在空白区拉框多选锚点、`Shift+点击` 增删选点、`⌘A` 全选锚点；支持多选锚点整体同步拖动、方向键/`Shift+方向键` 批量微调、`Delete` 批量删点与批量平滑/尖角转换，单步原子提交与 `⌘Z` 撤销；
- **Bend 弯曲工具**：矢量编辑浮栏新增「弯曲工具（Bend）」模式，默认模式下按住 `Option/Alt` 也可临时触发；悬停曲线段/直线段高亮，直接拖动线段实时弯曲（精确反解三次贝塞尔控制点，直线自动升格为曲线），在弯曲模式点击锚点一键切换平滑/尖角；
- **描边轮廓化（Outline Stroke · `⇧⌘O`）与文字转轮廓（Outline Text · `⇧⌘O`）**：
  - 选中带描边的可编辑矢量路径、矩形或椭圆时，可将描边（支持 `inside`/`center`/`outside`、端点 `butt`/`round`/`square`、拐角 `miter`/`round`/`bevel`、圆角）精准转为闭合填充可编辑矢量轮廓；
  - 选中可编辑文本图层时，支持将保留源字形轮廓（`sourceTextShape`）或已嵌入文档字体（`doc.fonts`，基于 `harfbuzzjs` `glyphToPath`）的文本转为可逐点编辑的原生矢量路径；对未嵌入字体字节的系统字体文本给出清晰可操作提示（引导先在字体资源中导入字体文件），不生成假图形、不崩溃；
  - 统一接入右键菜单、命令面板（`⌘K`）、属性面板快捷入口与 `⇧⌘O` 快捷键，完整支持锁定/实例保护、`⌘Z` 单步撤销、`.forma` 存取、预览与 React 导出。

## 四、验收标准（DoD）

1. **门禁与洁净度**：`npm run format:check`、`npm run lint:arch`（`0 violations`、`as any <= 1`、新增 CSS 全在 `@layer panels` 且 **0 新增 `!important`**）、`npm run build` 全部通过。
2. **单元测试**：全仓单元测试 0 失败，新增 2 套 Phase 2 专项单测（对齐/LOD 缓存 + 高级矢量多锚点/Bend/描边与文字轮廓化）。
3. **浏览器 E2E 与真实画板交互验收**：
   - 新增专项 E2E `canvas-phase2`（覆盖画板/分区标题拖拽、吸附、`Alt` 复制、多选拖移、双击原位 IME 改名、右键菜单、工具态透传；8 枚对齐/分布图标 SVG 方向与像素结果全核验；128 屏远景 `< 38%` 自动进入 LOD 缓存使 DOM 节点数大幅压降、点击瞬切活 DOM、放大 `>= 42%` 全回活 DOM、修改分支即时失效；矢量多锚点框选批量拖移、Bend 直接拖弯曲线、描边轮廓化与嵌入字体文字转轮廓及 `.forma` 保存重开/预览/React 导出）；
   - 既有全部核心浏览器回归 E2E 零破坏；
   - `npm run test:exports -- canvas-phase2` 导出 React 工程独立安装、构建与 Chromium 运行通过；
   - 同机生产预览复测 `complex`（8,288 层 / 128 屏）与 `layer-tree`（10,000 层）性能基准，额外记录 128 屏远景 LOD 前后 DOM 节点数与平移帧率实测对比；
   - 采集 2× Retina 深浅双主题实拍（含对齐工具栏高清特写、画板标题原位重命名/拖拽、128 屏远景 LOD 缩略图、矢量多锚点框选/Bend/轮廓化结果）并人工逐张核验；
   - 通过 `npm run release:run` 同步发布 **`v0.17.0`** 并完成只读挂载 `Forma-0.17.0-arm64.dmg` 实机验签与运行验收。
