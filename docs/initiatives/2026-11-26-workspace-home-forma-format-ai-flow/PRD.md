## 一、问题背景与用户实测痛点

在 `v0.12.0` macOS 桌面端实机走查中暴露出 5 项影响商业产品完整度的核心体验与功能缺陷：

1. **启动路径与「项目空间」割裂**：已引入项目与多设计文件概念，但打开 Forma 仍直接落入一张「未命名设计文件」默认画布，项目空间被隐藏在面包屑后的次级弹窗内。
2. **缺少自有原生设计文件格式**：`⌘S` / 保存本地副本输出明文 `<name>.forma.json`，macOS 将 `.json` 识别为扩展名，大图/字体经 Base64 膨胀约 33%，且无法内嵌封面缩略图。
3. **「新建设计」入口过弱**：项目文件弹窗与编辑器顶栏中「新建空白文件」均为无文字的 28px 小图标，缺乏清晰主次层级。
4. **已配置模型跨文件/重启误报「未连接模型」（实锤缺陷）**：配置好模型后新建设计文件、切换文件、刷新或重启桌面端，`agentStatus` 复位为 `null` 且未自动水合，导致反复提示「未连接模型」。
5. **「创作设置」浮层残留工程师思维**：暴露内部编译器选项（「生成方式：自动/精细排版/蓝图编辑」）、向非视觉模型展示禁用态「视觉优化」开关、将本地技能锁在模型连接之后，并把面向开发者的 MCP/JSON 接入塞进设计师创作浮层。

## 二、产品目标与验收标准

### 1. 全屏工作台首页（Workspace Home）与强新建入口
- 常规打开 Forma（无 `?file=` / `?example=` / `?editor=1` 且非双击文件启动）默认进入全屏 **Forma 工作台首页**，而非强行进入「未命名设计文件」画布；
- 首页提供左侧项目与空间导航（`最近打开`、`全部文件`、`未归类草稿`、`项目空间` + `+ 新建项目`、底部`模型与集成` / `内置示例` / `版本日志`）、顶部醒目蓝色主按钮 **`+ 新建设计`**（在某个项目下自动归入该项目）与次主按钮 **`导入设计文件`**、快速起步预设卡及大图缩略图画廊；
- 编辑器顶栏提供明确 **`← 工作台`** 返回首页入口及清晰的新建入口。

### 2. 原生 `.forma` 容器格式（`forma/package` v1）与桌面原生保存
- 定义并落地原生 ZIP 容器格式 **`.forma`**（包含 `manifest.json`、无 Base64 大图的 `document.json`/`document.parts.ndjson`、`preview.svg` 与原始二进制 `assets/images/*`、`assets/fonts/*`）；
- `⌘S` / 保存本地文件默认输出 **`<文件名>.forma`**；
- macOS 桌面端支持原生 `.forma` 保存体验：打开本地 `.forma` 文件后 `⌘S` 直接原子写回绑定路径，`⇧⌘S` 弹出原生「另存为 `.forma`」对话框；Web 端 `⌘S` 下载 `.forma`；
- 100% 向后兼容读取旧版 `.forma.json`，且 `.forma` ZIP 容器不与 `.sketch`/`.fig` 导入识别冲突。

### 3. 模型连接状态跨文件/重启自动保持
- 已配置过模型的用户，在新建文件、切换文件、刷新或重启桌面端后自动恢复已连接模型与技能列表，不再误报「未连接模型」；
- 从未配置过模型的干净环境仍严格保持 `0` 次 `/api/agent/*` 请求，纯手动编辑与导出完全离线可用。

### 4. AI 输入区彻底净化（移除「创作设置」弹窗）
- 移除「创作设置」按钮与浮层，删除内部「生成方式」下拉和禁用态「生成后自动视觉优化」开关（视觉模型默认自动质检，非视觉模型静默跳过）；
- 输入框底栏保留极简工具条：`@ 引用` + `上传参考图` + 紧凑内联 **`组件库切换药丸`**（默认自动继承当前项目默认组件库）+ `发送`；
- 技能管理独立为清晰入口且不再因未连接模型而无法管理；
- 「外部 Agent（MCP）与 JSON 事务接入」移入独立的 **「外部工具集成（MCP）」** 窗口（由顶栏 Forma 菜单与首页设置入口打开），关闭窗口时保持已配对 MCP 会话不断线。

---

## 三、明确不做（本轮边界）
- 不引入云端账号、远端文件同步或多人实时协作；
- 不改变已有 `schemaVersion: 1` 文档节点语义与 React 导出代码结构；
- 不移除对既有 `.forma.json` 的读取兼容性。
