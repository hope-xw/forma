## 一、背景与痛点证据

随 Stage 1（组件库智能理解）与 Stage 2（项目空间与历史记忆）连续交付，Forma AI 底层工程能力已十分扎实，但面向设计师的两处核心对话界面（左侧栏 `AgentPanel` 与画布悬浮条 `CanvasAgentBar`）出现了明显的**工程视角堆叠**：

1. **信息架构倒置（控制面板化，而非对话助手）**：
   - 左侧栏在未开始对话前即纵向堆叠 6 层状态与工程开关（标题栏 → `单稿记忆 0 条档案` → `未连接模型 + 3 图标` → 重复的蓝色 `配置模型` 提示条 → `目标组件库: 自动 / 不限库` → `智能模式 + 自审 + @ + 图`），占去大半面板高度；
   - 对话流被困在面板中部的 `max-height: 280px` 局部滚动盒中，缺乏主对话画布与吸底输入区；
   - 底部常驻「外部 Agent / 事务导入」，将开发者 MCP/JSON 调试入口直接暴露在主创作流末尾。
2. **文案高度技术化（泄露内部实现术语）**：
   - 暴露 `单稿记忆`、`0 条档案`、`自动 / 不限库`、`P1/B1/C2`、`智能模式 / 现代精排 / 蓝图编辑`、`自审`、`基于版本 N`、`create · Frame` / `insertComponent · xxx`、`事务导入`、`沙盒排版并编译` 等研发术语；
   - 未连接模型时，左侧栏重复提示 2 次、画布悬浮条重复提示 3 次（顶栏胶囊 + 占位文案 + 按钮）；画布空白处选区胶囊甚至直接暴露 `(x, y)` 像素坐标。
3. **代码单体膨胀导致 UI 与数据逻辑耦合**：
   - `src/editor/AgentPanel.tsx` 单文件达 **3,422 行、92 处 React Hooks**，混杂项目记忆持久层状态机、SSE 对话编排、HTML 沙盒编译、视觉自审与千行视图模板。

## 二、目标与设计原则

### 2.1 产品体验目标（设计师视角）
1. **真正的满高对话工作区**：左侧栏采用标准三段式对话布局（极简顶栏 + `flex: 1` 独立滚动对话/欢迎画布 + 吸底一体化输入卡片）。
2. **渐进式披露（Progressive Disclosure）**：
   - 默认零噪音：未归入项目且无历史记录时不展示「单稿记忆 0 条档案」琥珀标签；组件库、生成方式、自动视觉优化、本轮技能、外部 MCP/JSON 接入统一收口至输入框左下角「偏好设置」浮层；
   - 显式透明：一旦设计师主动选择了特定组件库、非默认生成方式或本轮技能，在输入框顶部以轻巧可移除标签明确呈现，绝不黑盒隐藏。
3. **去技术化、一致的人性化语言**：
   - 未连接模型在每处界面只提示 1 次，以温和引导卡替代红色/多重催促；
   - 进度提示、改动预览明细（操作类型转中文、隐藏内部版本号除非过期冲突）、生成过程折叠详情均以设计师可理解的语言表达；
   - 统一 `Enter` 发送 / `Shift+Enter` 换行（同时向后兼容 `⌘↵` / `Ctrl+Enter`）；
   - 画布悬浮条（`CanvasAgentBar`）去除未配置时的三重重复提示与原始像素坐标，提升视觉克制度与焦点层级。
4. **零能力退化**：Stage 1 / Stage 2 全部专业能力（项目记忆与抽屉、归档/置顶/删除/`@引用`、组件库选择与说明书概览、生成模式切换、视觉优化开关、本轮技能与技能管理、模型切换与能力展示、范围确认卡、实时预览与单步撤销、模块沉淀、外部 MCP 配对与手动 JSON 导入）100% 保留且离线零外网请求。

### 2.2 工程质量目标
1. 将 `src/editor/AgentPanel.tsx` 按职责清晰拆分为 `src/editor/agent/` 下 4 个高内聚子模块 + 主装配组件，保持对外导出的符号与类型 100% 向后兼容。
2. 零新增 `!important` 样式覆盖；双主题（深/浅）及窄屏（`1024×480`、`1280×650`）严格无横向溢出、对比度 ≥ 4.5:1。

## 三、明确不做（非目标 / 下期范围）

- 不改写后端 `/api/agent/*` 协议、`ModelConfigModal` 配置流程或 `SkillsModal` 技能管理弹窗（本期聚焦 AI 对话主面板与画布快捷栏）。
- 不重构 `App.tsx`、`Inspector.tsx` 或全仓 CSS 体系（在整体项目 Review 报告中作为后续独立路线图提出）。
- 不新增联网遥测或打破未配置模型时零外网请求约束。

## 四、验收标准

1. **视觉与交互**：真实 Chromium 下对深色 / 浅色主题、`1460×960` / `1280×650` / `1024×480` 视口完成前后对比截图核验，未连接态与已连接态均无信息堆叠、无横向溢出、无重复提示。
2. **离线与零退化**：`optional-gateway`（0 次 `/api/agent/*` 请求）、`agent-canvas-chat`（完整 Stage 1 + Stage 2 全链路）、`mcp`、`panel-parity`、`editor-panels` 全部通过。
3. **工程门禁**：`npm test`、`npm run format:check`、`npm run build` 全部通过。
