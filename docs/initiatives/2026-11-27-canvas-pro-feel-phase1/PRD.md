# Forma 画布一线手感升级（Phase 1 · v0.16.0）PRD

- **最近更新日期**：2026-11-27
- **状态**：已实施并验收（Phase 1 · 随 `v0.16.0` 发布）
- **目标版本**：`0.16.0`（Phase 1：极致跟手渲染管线 + 高频圆角/自动布局直操 + 宽域导航视野与小地图）
- **关联后续课题**：Phase 2（计划 `v0.17.0`：50–150 屏全景智能缩略缓存与动静切换 + 高级矢量多锚点框选/Bend/轮廓化）

---

## 一、背景与已确认痛点

基于 2026-11-27 对 Forma `v0.15.0` 的源码级诊断与业界一线工具（Figma、MasterGo、Pixso、Framer）对标：

1. **高频缩放与平移发涩**：[Canvas.tsx](../../../src/editor/Canvas.tsx) 每次 `wheel` 滚轮或双指捏合缩放直接调用 React `setViewport(next)`，触发 2,541 行 `Canvas` 组件整树重渲染及 DOM `frame-label` / 标尺 / 背景网格重绘，在 macOS 120Hz 触控板或大文件下产生明显主线程抖动。
2. **大文件命中测试存在 O(N) 瓶颈**：`containerAt()` 与 `sectionParentAt()` 在拖拽悬停时对 `doc.nodes` 做线性全表扫描，缺少空间索引；当页面画板数与容器数攀升至 50–150 屏（万级图层）时，拖拽与框选明显吃力。
3. **缺少设计师高频“画布肌肉记忆”直操**：
   - 选中矩形或画板时，无法在画布四角直接拖圆点调整统一/单角圆角；
   - 选中自动布局容器（`row`/`column`）时，无法在画布内悬停直接拖粉色内边距（Padding）与子项间距（Gap）手柄；
   - 缩放视野停留在 `5%–800%`（偏窄），高倍放大下像素网格基于 CSS 背景易模糊，对齐红线缺起止截线与紧凑数值浮标，百屏大画布缺少快速全局定位的画布小地图（Minimap）。

---

## 二、核心目标（本轮 Phase 1 必达）

1. **极致跟手的零 React 相机与空间加速底座**
   - 滚轮平移、双指捏合缩放、空格拖拽平移在手势进行期间通过 `requestAnimationFrame` + 相机频道直驱 `.canvas-world` CSS 矩阵与高频覆盖层，**交互帧内 0 次 React 整树重渲染**；手势停稳后防抖同步 React 状态供视口裁剪与界面读数更新。
   - 缩放范围由 `5%–800%` 扩展至 **`2%–6400%`**（`MIN_ZOOM = 0.02`, `MAX_ZOOM = 64`），平滑区分 macOS 触控板 pinch 缩放与普通鼠标滚轮缩放，保持锚点零漂移。
   - 引入纯领域空间索引 `SpatialIndex`，替换 O(N) 容器命中与视口相交遍历，确保万层文档下命中查询维持亚毫秒级。
2. **高频画布直操：圆角拖点 + 自动布局粉色 Padding/Gap 直拖**
   - **画布圆角直拖**：单选可编辑 `rectangle` / `frame` / `button`（未锁定、非实例内部受保护图层）且屏幕尺寸足够时，四角内侧浮现圆角圆点手柄；直接拖拽同步修改统一 `radius`（`Shift` 对齐 4px 步进），按住 `Option/Alt` 拖拽单独修改对应角 `corners.{tl,tr,br,bl}`；自动钳制至 `Math.floor(min(w,h)/2)`，拖动中显示实时数值胶囊，按 `Esc` 取消，松手单步 `⌘Z` 撤销。
   - **自动布局粉色直拖**：单选可编辑 `frame`（`layout === "row" | "column"`，未锁定、非实例内部受保护图层）时，在容器四边内边距区域与子项间隙处提供 Figma 风格粉色直操手柄（`#FF4D8D`）；拖动四边调节内边距（默认单边写入 `insets`，按 `Option/Alt` 对称调节对边，按 `Shift` 对齐 4px 步进，按 `Option+Shift` 四边同步），拖动子项间隙调节 `gap`（`justifyContent === "space-between"` 时自动禁用间隙拖拽）；拖动时实时预览与粉色像素读数显示，松手单步 `⌘Z` 撤销。
3. **一线视野与高精度 Canvas2D HUD**
   - **单层高 DPI Canvas2D 高频覆盖层**：在相机 120Hz 变动与拖拽期间零 DOM 抖动绘制高倍率清晰像素网格（`zoom >= 4` 或开启像素网格时）、增强版智能吸附红线（精确起止端点截线 + 红色像素读数胶囊）与 `Alt` / Dev Mode 微距红线标注。
   - **画布小地图（Minimap）**：右下角紧凑毛玻璃悬浮面板，实时缩略绘制当前页全部画板/分区/组件集轮廓与蓝色视口框，支持点击瞬移跳转与拖拽视口框逛百屏画布；提供视图选项菜单项与快捷键 **`⇧M`** 及顶栏开关按钮；常规小稿默认收纳不遮挡画布，当单页根画板数 `>= 6` 且**画布可视尺寸 `>= 1080×540`** 时自动温和展开（用户手动切换后尊重用户偏好）。

## 三、明确非目标（留待 Phase 2 / 后续版本）

- **Phase 2（`v0.17.0`）范围**：远景 `< 40%` 画板离屏位图瓦片缓存与动静切换、高级矢量多锚点框选/Bend 拉弯/文字与描边转轮廓、`App.tsx`/`Inspector.tsx` 细粒度外部 Store 拆解。
- **后续版本范围**：多人实时协作（CRDT）、云端版本历史时间线、渐进模糊/噪点/3D 特效、AI 生成引擎升级、Firefox/WebKit 全套跨引擎回归（本轮以 macOS `arm64` 桌面端 + Playwright Chromium 为主力验收）。

## 四、验收标准（DoD）

1. **架构与静态门禁**：`npm run format:check`、`npm run lint:arch`（`0 violations`、`as any <= 1`、新增 CSS 归入 `@layer panels` 且 **0 新增 `!important`**）、`npm run build` 全部通过。
2. **单测与新增自动化测试**：全仓单元测试 0 失败，新增 3 套专项单测（空间索引/相机/宽域缩放、圆角与自动布局直操事务、小地图几何投影）。
3. **浏览器 E2E 与真实性能对比**：
   - 新增专项 E2E 用例 `canvas-pro-feel`（验证 2%–6400% 缩放、滚轮高频缩放平移零 React 抖动、圆角统一/单角画布直拖与单步撤销、自动布局粉色 Padding/Gap 直拖与单步撤销、小地图 `⇧M` 展开与点击跳转、100+ 屏大稿压测与 `1024×480` 短窗无遮挡）；
   - 全量既有核心 E2E 回归零破坏；
   - 导出 React ZIP 独立安装、构建与运行通过（确认画布圆角与内边距/间距直拖修改 100% 同步到 React 导出工程，0 像素偏差）；
   - 采集改造前后 `layer-tree`（万层）与 `complex`（8,288 层 / 128 画板）+ 连续 60 帧滚轮缩放平移性能实测数据，输出客观对比记录；
   - 深浅双主题 2× Retina 实拍人工复核通过；
   - 通过 `npm run release:run` 自动升级发布 **`v0.16.0`** 并完成只读挂载 `Forma-0.16.0-arm64.dmg` 实机验收。
