# Forma 多文件顶部 Tab 工作台（Multi-Tab Workspace）PRD

- **状态**：已实施并验收（随 v0.14.0 发布）
- **启动日期**：2026-11-27
- **负责人**：Forma 产品与架构团队
- **关联长期规格**：[ARCHITECTURE.md](../../ARCHITECTURE.md) · [VERSIONING-AND-DESKTOP.md](../../specs/VERSIONING-AND-DESKTOP.md) · [EDITOR-UI-CONTROLS.md](../../specs/EDITOR-UI-CONTROLS.md)

---

## 一、背景与痛点

`v0.13.0` 已落地全屏工作台首页与原生 `.forma` 文件格式，但设计师在日常多稿并行作业中仍存在明显路径断层：
1. **不支持单窗口多开设计稿**：从工作台首页或面包屑打开文件会整页跳转覆盖当前画稿，无法像 Figma 一样同时开着 3–4 份设计稿来回对照或跨稿复制组件。
2. **macOS 桌面端多开体验割裂**：双击本地 `.forma`/`.fig`/`.sketch` 或 `⌘O` 每次都会强制新开独立窗口，缺少统一顶部 Tab 管理，容易造成满屏窗口。
3. **左上角菜单缺少「最近打开」触点**：在编辑器中想快速调出刚刚改过的历史设计稿，必须先切回工作台或打开二级弹窗。
4. **切换成本与长任务风险**：整页跳转会丢失上一份设计稿的视口缩放/选区状态，也会直接中断进行中的 AI 流式生成或 MCP 外部配对会话。

---

## 二、产品目标与核心交互（对标 Figma Desktop / Web）

1. **顶部 36px 全局 Tab 栏（跨 Web 与 macOS 桌面一致）**
   - 首位为**固定不可关闭的「工作台」Tab（`⌂`）**，随时一键切回工作台首页且保留所有已打开的设计稿 Tab。
   - 后续承载多个设计文件与内置样例 Tab：展示文件/样例图标、标题、未保存圆点（`•`）、AI 生成或 MCP 配对进行中的活跃状态点、悬停/激活关闭按钮（`×`）与中键关闭；支持**拖拽重排**与右键上下文菜单（关闭标签页 / 关闭其他 / 关闭右侧 / 重新打开已关闭 / 在新窗口中打开）。
   - Tab 栏末尾紧跟 **`+` 新建按钮**（`⌘T`）。
   - macOS Electron 桌面端采用 `hiddenInset` 融合标题栏，红黄绿原生窗口按钮自然融入 36px Tab 栏左侧拖拽区。
2. **全触点统一收口至顶部 Tab**
   - **工作台首页**：点击文件卡片/列表、快速起步卡片、样例、拖拽导入 → 无刷新新增或聚焦对应 Tab。
   - **左上角 `Forma ▾` 菜单 → 新增「最近打开 ▸」子菜单**：展示最近 10 个本机文件（含所属项目与时间），点击直接在新 Tab 打开或聚焦已有 Tab。
   - **本地文件打开**：`⌘O`、文件菜单打开、访达双击 `.forma`/`.fig`/`.sketch`、文件拖入 Tab 栏 → 桌面端默认送入当前主窗口的新 Tab（同路径已打开则直接聚焦）；仅显式 `⇧⌘N`「新建窗口」或右键「在新窗口中打开」才新建窗口。
   - **编辑器内新建与切换**：顶栏 `+ 新建`、`FileBrowser` 选文件、内置样例链接均走统一 Tab 调度器。
3. **标准快捷键与会话恢复**
   - `⌘T` 新建设计 Tab、`⌘W` 优先关闭当前文件 Tab（关至最后一份时切回工作台，在工作台按 `⌘W` 才关闭桌面窗口）、`⇧⌘T` 恢复最近关闭的 Tab（最多 10 个关闭栈）、`⌘1–9` 切工作台/对应 Tab、`Ctrl+Tab` / `Ctrl+Shift+Tab` 前后切换。
   - 重启 Forma 后自动恢复上次未关闭的文件 Tab 列表与激活项（自动剔除已删除文件）。
4. **可控内存与零打断长任务保活**
   - 切换 Tab 前自动落盘未保存改动并记录视图快照（当前页、视口缩放平移、选区），切回秒级还原位置与选区，避免十几个大画布常驻 DOM 造成内存暴涨。
   - 正在进行 **AI 流式生成** 或保持 **MCP 外部配对** 的 Tab 自动锁定保活（隐藏渲染不断链），允许设计师自由切到其他 Tab 查看参考稿。

---

## 三、明确不做 / 下期范围

- 暂不做跨两个独立窗口拖拽合并 Tab（本期提供右键「在新窗口中打开」与 `⇧⌘N` 新建窗口）。
- 暂不做同一窗口左右分屏双画布编辑。
- 暂不在本课题内改造 MCP 底层传输协议或实现 A2A Server（已单独评估规划）。

---

## 四、验收标准

1. 默认打开 `/` 展示顶部 Tab 栏（工作台 Tab 激活）与全屏工作台首页，未配置模型仍保持 `0` 次 `/api/agent/*` 请求。
2. 分别通过 **工作台首页、左上角 `Forma ▾ → 最近打开`、`+` 按钮、本地打开/访达双击** 同时打开至少 3 份设计稿，验证无刷新切换、同文件去重聚焦、视口/页面/选区还原、拖拽重排、`⌘W` / `⇧⌘T` 关闭与恢复、刷新重启恢复 Tab 会话。
3. 验证背景 Tab 保持 MCP 配对会话在切去另一份设计稿期间不中断。
4. macOS 桌面端只读挂载 DMG 实机验证融合标题栏、`open-file` 进入现有窗口新 Tab、全量门禁与 2× Retina 深浅主题实拍通过。
