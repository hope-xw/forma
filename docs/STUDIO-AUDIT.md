## 面板操作复核 · 1280 × 650 与 1024 × 480

- 修复前：右键菜单有 33 项，内容比可视区高 540px。在 622 层页面滚轮操作后，左栏滚动 874px，页面栏顶部位于 −778px，图层树本身滚动为零。
- 修复后：同样操作下图层树滚动 850px，左栏滚动为零，页面栏、搜索栏、画布位置不变。空白画布右键为 6 项，对象菜单按上下文分组；测试了视口底边、480px 高窗口、键盘进入与返回子菜单。
- 实际编辑图形并读取浏览器样式：47px 左上圆角、径向渐变叠加、下移及隐藏另一填充、multiply 混合、dashed 描边；刷新后保留。下载 React ZIP 后独立构建，导出页面也渲染了以上属性。复核脚本：`scripts/check-editor-panels.browser.js`。
- 本节记录 11 月 17 日的基线。约束、旋转、富文本以及跨页原型的后续浏览器验收见[编辑器验收记录](EDITOR-ACCEPTANCE.md)。

## 性能采样

同机同一有头 Chrome 会话，1637 × 899、DPR 2。在原库 Examples 与本地生产构建之间顺序采样；各 12 次点击，计时从 pointerdown 到观察到目标选区属性并再过两次 requestAnimationFrame，包含自动化观测开销。两个文件并非相同场景。

| 操作 | 中位数 | P95（12 次中的最大值） |
| --- | ---: | ---: |
| Forma 在侧栏、分享画板间切换选区 | 27 ms | 32 ms |
| Figma 在对应参考对象间切换选区 | 116 ms | 188 ms |
| Forma 切换 3 个页面并显示预期数量的节点 | 31 ms | 351 ms |

另外在独立 Chromium 会话对 622 层页连续提交 8 次坐标修改，输入确认到目标样式更新并再过两帧为 61–77 ms。已通过复制整页后 ID 重新生成、改名、删除/撤销、视口恢复、刷新保存的浏览器检查。自动化脚本为 `scripts/bench-studio.browser.js` 和 `scripts/check-studio.browser.js`。

这些数据只支持本次文件规模、设备与操作。首次进入重页有明显长尾；没有证明万层拖拽、缩放帧率、GPU/内存或多人协作达到 Figma 水平。后续应以相同文件负载测持续操作，并拆分 JS、React 提交和绘制耗时。
