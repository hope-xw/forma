# Forma Mobile 组件库 · 2026-11-17

以下为各次验收当时的记录。2026-11-20 更新后的能力、样例规模与复测脚本见[当前验收记录](EDITOR-ACCEPTANCE.md)。

用户已确认采用自研、可分发的移动 UI 库，以 iOS / iPadOS 27 套件作为能力和视觉组织参考，不打包 Apple 原始资源。本轮不是官方套件的完整复制，也不是经过逐变体视觉比对的替代品。

0.3.0 的内置库为修订 2，含 44 类、290 个变体；根层固定本变体的专用 Light 或 Dark 模式。四个样例页含直接属性变量绑定的图层依次为 147、227、268、236，统计不包括库模板和渐变色标。旧文件可从资源区审阅「更新内置组件库」。已逐一切换 290 个变体、核对根尺寸和预览层数，每类插入一种并下载验证引用。逐变体的实际 ID 与浏览器在[原始读数](evidence/2026-11-20/v0.3.0/results.json)。

## 当前入口

1. 打开资源面板，在组件页搜索、按分类筛选，选择浅色或深色。
2. 点击组件，预览其外观、尺寸、状态等属性，插入画布。
3. 右侧实例属性可切换变体。原生子图层可覆盖文字和外观；组件默认保护内部结构与几何，图层树以菱形、实例标记与默认折叠体现边界。
4. 实例可以重置覆盖、分离为普通图层；操作均支持撤销。增删、移动、重排内部图层或改变内部几何会被事务层拒绝，必须先显式分离。旧文件中已被拆改的实例仍可读取，切换时提示分离或重置，避免丢失编辑。
5. 页面页提供手机设置、内容发现、平板工作空间以及声场音乐工作台四个模板，均有浅色和深色，资源卡片显示真实图层缩略图。
6. 预览可操作输入框、开关、复选框、滑块、步进器和分段控件。
7. 选择一个画板，点击“导出 React 项目”。ZIP 包包含 React/TypeScript 源码、共用控件运行时、构建配置和原生设计文件。画板在无限画布上的位置归零，内部布局保持。
8. “供 Agent 使用”将组件库登记到当前文档。Agent 可通过 insertComponent 使用精确组件/变体 ID；真实模型仍需本地配置。

## 覆盖范围

当前 **44 类组件、290 个变体**。所有组件为原生 Frame、文本、形状和矢量路径，不使用整张截图作为实现。

| 分类 | 自研组件 |
| --- | --- |
| 输入与操作 | 按钮、图标按钮、开关、复选框、分段控制、文本输入、搜索、滑块、步进器、弹出选择、颜色选择、日期选择、时间选择 |
| 导航 | 导航栏、标签栏、工具栏、侧边栏、分页指示 |
| 内容 | 列表行、内容卡片、信息小组件 |
| 浮层 | 提示对话框、操作面板、半屏面板、菜单、上下文菜单、气泡浮层、分享面板 |
| 反馈 | 进度条、通知、空状态、通用验证提示 |
| 媒体与复杂页面 | 专辑卡片、侧栏导航项、曲目行、编辑精选、专注混音、玻璃播放器 |

主题为显式变体；基础规范包括语义颜色和文字层级。系统字体使用浏览器回退栈，图标为项目自绘路径。材质支持透明度、描边、阴影、背景模糊，以及 2–8 色标的线性/径向渐变；并不等价于 Apple Liquid Glass 的折射和渲染效果。

- Layout Guides、Product Bezels、官方 Examples 的全部模板并未复制；当前提供四个独立设计的页面模板。

## 实现分层

- domain/node.ts：可校验样式、矢量数据、控件语义与实例引用。
- domain/library-schema.ts：组件库、组件、变体及模板完整性校验。
- domain/library.ts：实例化、变体切换、覆盖保留、分离、选区保存。
- domain/commands.ts：原子事务；组件展开、锁定和不可覆盖已使用定义的约束。
- design-system/：原生设计系统的基础规范、组件定义和组合模板。
- editor/AssetsPanel.tsx、InstanceInspector.tsx：组件浏览、导入导出与实例编辑。
- runtime/FormaRuntime.tsx：预览与导出共用的控件运行时。
- compiler/runtime.ts：页面范围解析、结构编译和独立项目文件生成。
- infrastructure/export-project.ts：ZIP 打包与下载。

库以不可变快照随文档保存。修改已使用定义时保留原版本，冲突导入采用新 ID；复制实例到另一文件会携带依赖并处理 ID 冲突。常规插入仅携带所用组件，启用 Agent 时登记完整目录。发送给模型的库内容压缩为组件/变体目录，不重复发送全部模板图层。

## 验证与未完成项

本轮核心测试覆盖库校验、实例覆盖/重置/分离、嵌套文字保留、结构编辑保护、跨文件复制、版本冲突、Agent 范围约束和模板组合。浏览器已通过两组共 29 项检查，包含真实输入、键盘控件、深色平板、刷新恢复与 ZIP 下载；导出工程独立 TypeScript 检查和构建通过。

2026-11-17 当时尚未实现：Hug/Fill、断点与自适应布局、嵌套主件的递归更新传播、组件变量别名/主题继承、完整富文本与图像资源、官方全部控件状态和尺寸、菜单/弹层/日期选择的流程交互及系统 API、复杂原型状态机。当前菜单、日期/时间面板、键盘、窗口与验证提示是可编辑设计组合。业务事件通过导出的 onAction 接入，不包含业务后端。

保存仍是浏览器 localStorage，组件库导入上限不等于浏览器可用配额；失败时会明确提示导出备份。多端协作和大文件存储仍在路线图中。


## 2026-11-17 复杂页面与组件保护增量

- 声场音乐工作台：1440 × 1024，311 图层、94 矢量、20 组件实例、11 渐变。侧栏、精选、原创封面、声波、曲目列表、队列与浮动播放器组成完整页面。原生文件见 `examples/`。
- 保护规则覆盖鼠标、图层拖放、快捷键、属性修改与 Agent 事务。禁止直接移除实例元数据；新实例需匹配来源图层图和顺序。分离与变体切换使用显式领域命令，不开放内部绕过参数。
- 组件内可深选、改文字与外观；几何字段和删除按钮禁用并解释原因。普通画布点击停留在实例边界。实例内部不显示尺寸把手。
- 整体复制粘贴携带组件定义；选中组件或其子层时粘贴、资源插入落在组件同级。系统剪贴板权限悬挂有超时和工具内缓冲回退；异步操作期间文件变更会拒绝陈旧操作。
- 复制样式仅包含外观，不携带布局规则；渐变结构在画布、预览、静态 React 和工程导出中共用计算。
- 浏览器已打开参考文件 Examples 页面与 iPad 目录。此音乐页面是自研复杂组合，不宣称逐像素复刻某个 Apple 官方页面。

媒体播放器、导航、搜索与专注按钮目前为视觉组合，尚未绑定业务行为；这一轮没有把它们计为复杂原型状态机。响应式、图像资源、主件更新传播与多人协作继续保留为未完成项。
