## 文本图层原位编辑

双击文字或按钮文案，或选中后在画布按 Enter，直接在图层内编辑。焦点框绘制在图层边缘，选区工具栏保持屏幕尺寸。图层的字距、行高、字形样式、水平与垂直对齐、描边、换行、父级布局和旋转在切换时继续生效。点同一文本框的留白可继续输入，点外部、Esc 或 Ctrl/⌘+Enter 提交；普通 Enter 插入换行。空文本保留一个行高的输入位置，末尾换行保留一行空白。画布、预览、独立工程与 Hug 测量一致。[画布图层](../../src/editor/CanvasNode.tsx) · [文字编辑](../../src/editor/InlineText.tsx) · [逐字与像素验收](../EDITOR-ACCEPTANCE.md#065-文本图层原位编辑)

## 位图填充与裁切

| 入口 | 可核验行为 |
| --- | --- |
| 右栏「图像填充」 | 适配模式有填充、适应、拉伸和平铺。X/Y 是 0–100% 的相对焦点。平铺时输入 × 控制原图天然宽高的 0.1–8 倍；其他模式使用原有 1–8 倍的裁切倍率。切换适配再返回可继续使用原倍率。 |
| 画布裁切 | 可从右栏裁切图标进入，普通位图图形也可双击。拖网格区域平移图像，拖右下角等比缩放。没有可移动余量的轴保持原焦点。每次松手只记一次修改；拖动中按 Esc 回到本次拖动前的数值并退出。方向键调整焦点 1 个百分点，加减键调整 0.1 倍，Shift 放大十倍。Enter 或双击结束。锁定对象禁用编辑；平铺用右栏数值调整。 |
| 右栏「图像调色」 | 亮度、对比度、饱和度按此顺序各取 0–200%，100% 为原值，一次重置可撤销。只处理位图，保留其透明度以及上方的填充。 |
| 交付 | CSS 预览与 React 工程使用相同的裁切和重复周期，静态 SVG、PNG 及位图蒙版使用同一源图与参数。普通位图以描边内边界确定可绘制区域，内描边宽度计入裁切与平铺起点。旧设计沿用原始适配与色彩。此次对照项为适配、平铺、焦点、倍率、三项调色和蒙版，色温、高光、阴影等其他调色能力仍在边界外。 |

Figma 对照项包括按原图比例平铺、双击图层进入裁切、平移、缩放和 Enter 结束。Forma 的亮度按倍率调整 RGB 通道。Figma 的曝光、色温、图像独立旋转和裁切边框手柄还有差异。[Figma 图像属性](https://help.figma.com/hc/en-us/articles/360041098433-Adjust-the-properties-of-an-image) · [Figma 裁切操作](https://help.figma.com/hc/en-us/articles/360040675194-Crop-an-image)

## 分支和分区

在「编辑锚点」选择起点，点「从锚点连接分支」。点击空白处生成开放边，点击同一单轮廓区域的不相邻锚点可用一条弦分成两个区。相邻锚点已有边，重复连接会提示原因。右栏「路径」切换区域后可分别设置颜色。移动共用锚点或按方向键调整会同步其所有连接；Esc 取消正在等待目标的操作。按松手或一次按键提交事务。验收覆盖分区、接出第三条边、撤销、重开、预览与导出。[编号 03.04 与 04.15](EDITOR-PANEL-ACCEPTANCE.md)

## 在画布管理组件集

从「组合为变体集」创建带虚线轮廓的画布组。原有文件可在本地主件的「组件变体 → 在画布排列组件集」进入同一工作流。第一条属性轴作列，其余属性组合作行，成员间距 24 px。将独立的同类型普通层或主件拖到组内的空白处。已有主件使用副本加入，保留历史发布的来源。使用中的变体须先切换使用方；非默认变体可在主件面板「移出变体集」。[编号 04.17](EDITOR-PANEL-ACCEPTANCE.md)

## 容器外观与组件改名

自由布局与 Hug 宽度画板可直接设置外观断点，此时原有自动布局参数保留在文档中，切回适用的布局后生效。在右栏「容器断点」设置填充、圆角（0–1000 px）和不透明度（0–100%）。使用现有颜色选择器或 HEX 输入。填充右侧的恢复按钮清除当前区间的颜色；数值输入框清空后继承。取容器自身的边框盒宽度。较窄区间继承较宽区间的显式值，超出所有区间时恢复原样式和变量。填充覆盖为纯色，圆角覆盖四角，透明度作用于整个容器。可在一个区间中同时编辑布局与外观，一次提交可撤销。画布、预览和 React 使用同一个断点解析器。

在本地主件「公开组件属性」中直接编辑现有名称，Enter 或失焦提交，Escape 取消。属性 ID 和目标模板键保持稳定。已发布过的旧名字保存在该属性的 `previousNames`，每项最多 100 个，组件内含旧名在内不得重名。实例右栏显示现名；工程 `values` 接受现名与旧名，同时传入时现名优先。显式移除属性会从生成的接口移除该字段。

## 布局与画布

选择网格画板，在右栏「布局 → 网格轨道」切换行和列。固定尺寸用 px，剩余空间按 fr 分配，「适应内容」用内容宽高。每个方向最多 64 条自定义轨道。清除覆盖可恢复等宽列或默认行高。旧稿继续使用原有列数及固定行高。在自动适配最小列宽模式中，由容器宽度决定列数。

选择网格直接子层，在「单元格位置」指定从 1 起算的行、列，另可设置跨度。先保留指定单元格，再按图层顺序排列自动子层。窄容器列数不足时，先缩小跨度，再约束起始列。画布中拖动子层时显示目标格；松手提交一次，撤销可返回原位置。

选中可编辑网格画板时，顶部的紫色短线调整列宽，左侧短线调整行高。拖动将该条轨道换成固定像素，其余轨道保留单位。方向键调整 1 px，Shift 加方向键调整 10 px，拖动中 Esc 取消。锁定、实例内部和自适应列网格遵守已有结构保护。当前显式列把手位于相邻列的分界处。

### 多断点和嵌套容器

选中水平、垂直或网格画板，打开「容器断点」。每个容器最多新增 8 条规则，最大宽度从 1 至 10000 px。每条规则可单独覆盖间距、行间距和统一内边距，固定列网格还可覆盖列数。空白值继承更宽断点或基础值。断点按容器自身的实际边框宽度从宽到窄依次生效。嵌套工具栏可以独立于外层画板应用断点。宽度为 Hug 时面板不提供新增规则，避免内容决定宽度同时宽度改变内容布局。旧文件中的单个窄网格断点继续生效。

## 位图蒙版与文字

在同一父层选择位图和待遮罩的内容，从右栏应用「用作位图蒙版」。在蒙版组选「蒙版类型」切换矢量、透明度或亮度。透明度取位图 alpha，亮度同时考虑灰阶和 alpha；画布、播放器、生成的 React 使用同一裁切和蒙版计算。通过图层树可以再次选中来源修改裁切。

文本右栏「导入字体」可嵌入不超过 16 MiB 的 TTF/OTF。字体带有可变轴时，右栏按字体自身的范围提供滑块与数值输入；OpenType 字形列表取自字体自身的 GSUB/GPOS 特性。高级输入可指定四字符标签。双击进入文字、选中范围、打开「选区字体设置」可调整局部轴、OpenType 与字距。文档保存字体数据，独立 React 工程使用本地资源和 @font-face。分发字体时须使用有相应授权的文件。

多选不同渐变的图层，单改色标颜色保留各层原透明度，编辑透明度保留各自颜色。多选新增阴影分别追加在每层原有列表后，已有描边的图层保留原宽度与颜色。用一次撤销恢复本次批量操作。

## 主组件、实例与跨文件修订

选中本地主组件，在「公开组件属性」选择子层、设定名称并添加文本或显示属性。如果主件内已有一个组件实例，可以把它公开为「嵌套实例替换」。使用方从外层实例右栏选择同根类型的另一个已安装组件和变体，或恢复主组件默认；替换件保持槽位的位置、约束和尺寸。收到所选内层组件的新修订时，引用它的外层实例也参与审阅和更新。选中实例根即可修改这些属性、切换变体、替换兼容组件、重置或分离。替换保留根 ID、位置以及可匹配的已有覆盖。若新变体无法承接已编辑图层，操作会中止并提示具体图层。独立 React 组件的 values 属性按公开名称接收文字、布尔值或 React 子组件。例如 `values={{ 标题: "分享", 标识: <Badge instanceId="author" /> }}`。

在外层主件的「公开组件属性」中选「来自嵌套实例」，选择例如「Toolbar / 标识」并给使用方命名。已公开的字段可逐层转交。三层页头可在最外层修改标题或替换最内层标识；原位框、独立覆盖和代码中的公开名称都保留。如果上下两层同时替换，先匹配外层，再应用内层；不兼容的替换会提示。

### 创建自己的组件变体

在画布选中普通图层，按 ⌥⌘K（Windows/Linux 为 Ctrl+Alt+K），或从右键「组织 → 创建组件」、命令搜索、资源面板「保存选区」创建主组件。锁定或受保护的内部图层显示相应的前置条件。

在本地主组件右栏展开「组件变体」，输入属性名（如 State）、默认值 Normal 和新增值 Busy，点击加号。画布出现可独立编辑的同级主件，其初始位置在同组最右画板右侧 32 px。再从属性菜单新增 Size，可以分别设计 Busy/Regular 和 Busy/Large。铅笔图标可更名属性；修改属性名作用于整组，修改值作用于当前变体。一个组件最多 200 个变体，同一组中的完整属性组合须唯一。选中使用方实例后，只能切换到实际存在的组合；「定位主组件」前往当前变体的源图层。

也可在图层栏同时选择 2 至 200 个同类型、互不包含的可编辑图层，展开「组合为变体集」，填写名称与每个状态的值。普通图层直接成为源图层；已是主件的选区以副本加入新组，保留原主件、原实例和兼容的公开属性。修订、导入以及工程导出均按稳定的组件和变体 ID 匹配。「移出变体集」保留画布上的设计。默认变体、文件中仍被实例或嵌套替换使用的变体受保护。

业务页可使用生成组件的 `variantProperties={{ State: "Busy", 尺寸: "宽版" }}` 选择完整属性组合，同时传入 `values={{ 文案: "待发送" }}`。已有代码仍可通过稳定的 `variant` 标识选择。[Figma 变体工作流](https://help.figma.com/hc/en-us/articles/360056440594-Create-and-use-variants)

### 多选与跨文件使用

在图层树用 ⌘/Ctrl 点选多个实例。属性栏显示它们共有的同名、同类型公开属性和变体轴。值不同显示 Mixed，显示开关呈半选；离开未输入的混合文本框会保留各自内容。更改变体轴只改该轴，其他轴按实例保留，所有选中项共用一次撤销。

在资源面板打开本地主组件详情，展开「发布组件库」。本机运行的编辑器可直接使用默认发布服务。团队部署可填 HTTPS 服务地址与发布凭证，发布凭证仅用于本次发布会话。第一次发布要求远端不存在，同一地址更新要求 ETag 匹配且修订号递增。发布成功后复制面板中的订阅地址。本机回环地址供同一台电脑使用，团队共享使用可从使用方访问的服务地址。

在另一份文件打开「资源 → 在线组件库」，粘贴地址订阅。允许跨域读取的静态组件库 JSON 或 Forma 发布服务都可作来源。设计文件保留库快照，网络中断时继续编辑；联网后可按组件勾选修订。展开变体可并排查看当前与新版的外观、根尺寸及层数。变量或样式冲突会显示字段和双方实际值。对双方修改的同名变量、集合或样式，选择保留本地或采用新版。未选组件仍可在下一次检查时更新。撤销恢复应用前的快照与实例。取消订阅保留本地组件。订阅链接按本机文件保存，不随导出的设计文件自动联网。

自托管服务使用 `npm run dev:libraries`，默认绑定 127.0.0.1:5181。团队部署通过 `FORMA_LIBRARY_HOST`、`FORMA_LIBRARY_PORT`、`FORMA_LIBRARY_DIRECTORY`、`FORMA_LIBRARY_ORIGINS` 和 `FORMA_LIBRARY_WRITE_TOKEN` 配置。对外监听需要发布凭证。桌面版的本机发布服务仅监听回环，之前已发布的库随应用重新打开。当前权限粒度是服务写凭证与允许的编辑器来源。

## 键盘入口与回归

从新文件按 F 再按 Enter 插入画板。保持画板选中，按 T、Enter 插入文本，再按 Enter 直接编辑，⌘/Ctrl + Enter 提交。F6 在工具栏、可见左栏、画布和可见右栏之间移动焦点，Shift + F6 反向。画布内 Tab 继续用于相邻图层。

`npm run test:browser -- professional-editor container-rules mixed-materials mixed-instances keyboard-authoring component-properties variant-authoring nested-instances library-publish library-subscription` 覆盖上述入口。然后运行 `npm run test:exports -- professional-editor container-rules component-properties variant-authoring nested-instances forwarded-instances`，验证界面实际下载的 ZIP 独立构建与业务组件参数。网格、蒙版、文字和组件库的比较口径见 [Figma 网格](https://help.figma.com/hc/en-us/articles/31289469907863-Use-the-grid-auto-layout-flow)、[蒙版](https://help.figma.com/hc/en-us/articles/360040450253-Masks)、[文字属性](https://help.figma.com/hc/en-us/articles/360039956634-Explore-text-properties)、[组件属性](https://help.figma.com/hc/en-us/articles/5579474826519-Explore-component-properties)、[库](https://help.figma.com/hc/en-us/articles/360041051154-Guide-to-libraries-in-Figma)。
