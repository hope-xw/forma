# 声场音乐工作台

在 Forma 顶栏「设计文件 → 导入」选择 `soundspace-light.forma.json` 或 `soundspace-dark.forma.json`，也可从「资源 → 页面 → 平板 · 声场音乐工作台」插入同款页面。

1440 × 1024；311 个原生图层、94 个矢量图层、20 个组件实例、11 个渐变填充。封面为原创矢量山景，未使用 Apple 图像、图标或字体资产。

实例默认保护结构。可编辑文字与外观覆盖，整体移动或复制；右侧「分离组件」后可改内部结构，撤销可恢复保护。此示例验证固定布局和视觉导出；播放器、导航和搜索是设计组合，没有音频播放、搜索业务或导航流程。

示例由 `src/design-system/mobile-media-template.ts` 和原生移动组件库生成。React 工程通过工具内「导出 React 项目」获得。
